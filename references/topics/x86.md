# x86-64 topic areas

## Areas

- `Registers and arithmetic`: register sizes, data movement, integer and bitwise operations, flags.
- `Control flow and stack`: comparisons, conditional jumps, loops, `push`/`pop`, `call`/`ret`.
- `Functions and the ABI`: prologues, stack frames, argument registers, calling C.
- `Linux syscalls and memory`: `write`, `read`, `openat`, buffers, `argv`, `brk`, `mmap`.

## Easy

One main idea, at most 20 lines of user code.

### Registers and arithmetic

- Register sizes and aliases: `rax`/`eax`/`ax`/`al`
- `mov` with registers, memory, and immediates
- `movabsq` for 64-bit immediates
- `add`, `sub`, `inc`, `dec`, `neg`
- `and`, `or`, `xor`, `not`
- `shl`, `shr`, `sar`
- `lea` for address arithmetic

### Control flow

- `cmp`, `test`, and one conditional jump
- `setcc` and `cmov` for branchless selection
- Counted loops with `dec` and `jnz`
- `push`, `pop`, and stack slots
- One `call` and `ret`

### Data and syscalls

- `.data`, `.bss`, and RIP-relative operands
- Byte, word, dword, and qword loads and stores
- The `exit` syscall and its status
- A fixed string with the `write` syscall

## Medium

Areas added at this level. Medium includes every easy topic.

### Functions and the ABI

- Prologue and epilogue with `rbp`
- Saving and restoring callee-saved registers
- SysV argument and return registers
- Stack alignment before `call`
- Local buffers on the stack
- Calling a C function from assembly

### Widths and arithmetic

- Byte, word, dword, and qword operations
- `movsx` and `movzx` sign and zero extension
- `imul`, `mul`, `div`, `idiv`, and `cqo`
- Addressing modes: base, index, scale, displacement
- Array indexing with a scaled index

### Syscalls and buffers

- `openat`, `read`, `write`, `close`
- Syscall error returns in `rax`
- Byte and string loops with `rep movsb`, `rep stosb`, `scasb`
- `argc` and `argv` on the stack at `_start`
- Reading and writing a stack buffer
- Multiple functions in one file and local labels

## Hard

Areas added at this level. Hard includes every easy and medium topic.

### System utilities

- Multi-file programs with `.global`
- `strlen`, `strcmp`, `memcpy`, `memset` from scratch
- Decimal and hexadecimal conversion
- `cat`, `wc`, and `hexdump` style utilities
- Output buffering with `write`
- `brk` or `mmap` allocation
- Mixed C and assembly programs
- Syscall error handling and exit status propagation
